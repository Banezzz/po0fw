快速开始

1. 获取 token

在 po0 控制台的机器详情页，找到「防火墙」卡片，点 复制添加脚本（不是「添加当前 IP」）：

防火墙
仅允许白名单中的最近来源 IP 访问入站端口。
● 已开启
当前来源 IP
203.0.113.•••
白名单5 / 5
📋 复制添加脚本👈
🛡 添加当前 IP

加白接口形如下面这段，你的 token 就是 URL 路径里 pgnfw_ 开头的那一整串：

curl -X POST https://124.221.69.228/api/firewall/pgnfw_你复制到的这一整串/add

把 pgnfw_… 那一整串提取出来就是本机 token。一台机器对应一个 token，多个 token 用英文逗号分割。

🔑 token = 该机器的加白凭证，请妥善保管、不要公开分享。它只需填进你自己的客户端配置。
进阶：固定槽位。默认加白按最近使用时间自动淘汰最旧 IP。若想让某台机器（如家宽出口）常驻不被淘汰，在它的 token 后加 @槽位号，例如 pgnfw_你的token@0——脚本会请求 …/add?slot=0 把它钉在 0 号槽位。注意每个 IP 只能占一个槽位，换槽前需先在面板删掉旧槽位。

Clash 系 · Mac / Windows / Android

做不成模块。 Clash Verge Rev 和 FlClash 共用 mihomo 内核，没有 cron / 网络变化脚本这个插孔。改由系统调度器跑同一句 POST /api/firewall/<token>/add。服务端按 C 段（/24）加白，同一个出口只需一台设备上报。

TUN 开着时必须先加 DIRECT。 系统流量全进 mihomo，curl --noproxy 绕不开。漏了这一步脚本会显示成功，但服务端看到的是代理出口 IP，等于白加。
prepend-rules:
  - IP-CIDR,124.221.69.228/32,DIRECT,no-resolve
  • Clash Verge Rev：订阅 → 全局扩展配置（Merge）→ 粘进去。写在这里订阅更新冲不掉。Verge 2.x 若当前是 mode: global，规则本身不走，还要让脚本/TUN 把这个 IP 排除出隧道（macOS 安装说明里有）。
  • FlClash：设置 → 覆写 → 规则，直接追加那条 IP-CIDR（不用 prepend-rules 包装）。

会出门的笔记本 / 手机不要加 @槽位。白名单只有 5 个坑，只让一台始终在家的设备钉槽；出门设备钉了，家里 WAN 会被挤掉。

通知默认打开，跟 Shadowrocket 同一套：只在出口 IP 或加白状态变了才弹，例行定时保持安静。标题是 po0 防火墙加白。

macOS（launchd）

mkdir -p ~/.po0fw && cd ~/.po0fw
curl -fsSL -o po0fw.sh        https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.sh
curl -fsSL -o po0fw.notify.sh https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.notify.sh
curl -fsSL -o po0fw.conf      https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.conf.example
chmod +x po0fw.sh
# 编辑 po0fw.conf，填 PO0FW_TOKENS（出门的本子不要加 @）
./po0fw.sh -v

curl -fsSL https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/com.po0fw.whitelist.plist \
  | sed "s|__PO0FW_DIR__|$HOME/.po0fw|g" > ~/Library/LaunchAgents/com.po0fw.whitelist.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.po0fw.whitelist.plist

登录立刻跑、每 10 分钟、切 WiFi / 换 DHCP 自动触发。睡眠期间不跑，唤醒后补一次。证书报错就 ./po0fw.sh --pin，把两行贴进 po0fw.conf。

Windows（任务计划程序）

用管理员 PowerShell。常住家里的那台加 @0 钉槽。

mkdir C:\po0fw ; cd C:\po0fw
irm https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.ps1          -OutFile po0fw.ps1

Android（Termux 上报 + MacroDroid 切网）

蜂窝出口家里那台覆盖不了，手机要自己报。上报和通知放在 Termux 的 po0fw.sh 里（TLS 完整，通知跟 Shadowrocket 一样：变了才弹）。MacroDroid 只负责切网时把脚本喊起来——全程在 APP 里点，不用写代码，也不要让它自己发 HTTP。

第 0 步：装 APP

Termux 三个必须同一个源（F-Droid 或 GitHub，别混、别用 Play 商店版 Termux）。MacroDroid 随便装。

APP干什么F-Droid
Termux跑脚本com.termux
Termux:API通知栏com.termux.api

MacroDroid盯切网官网 / 应用商店

三个 Termux APP 签名必须一致。混装的话 termux-* 命令会静默卡住、零报错。先验 termux-battery-status，打出 JSON 才算通。

第 1 步：Termux 一段粘贴

先关 WiFi 切到移动数据，才能看到蜂窝出口。把 token 换掉，整段粘进 Termux。手机不要加 @槽位。

pkg update -y && pkg upgrade -y && pkg install -y curl termux-api
curl -fsSL -o ~/po0fw.sh        https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.sh
curl -fsSL -o ~/po0fw.notify.sh https://raw.githubusercontent.com/Banezzz/po0fw/main/clash/po0fw.notify.sh
chmod +x ~/po0fw.sh
cat > ~/po0fw.conf <<'EOF'
PO0FW_TOKENS="pgnfw_你的第一个|pgnfw_你的第二个"
PO0FW_TLS="strict"
PO0FW_NOTIFY="change"
EOF
chmod 600 ~/po0fw.conf
~/po0fw.sh -v

mkdir -p ~/.termux ~/.termux/tasker
grep -q '^allow-external-apps' ~/.termux/termux.properties 2>/dev/null \
  || echo 'allow-external-apps = true' >> ~/.termux/termux.properties
ln -sfn ~/po0fw.sh        ~/.termux/tasker/po0fw.sh
ln -sfn ~/po0fw.conf      ~/.termux/tasker/po0fw.conf
ln -sfn ~/po0fw.notify.sh ~/.termux/tasker/po0fw.notify.sh
termux-reload-settings
pkg upgrade 不能省。 只 update 再装 curl，会和新旧 openssl 对不上，后面全是 No such file。已经踩了跑 pkg upgrade -y。

看输出的出口 IP：运营商蜂窝段才对；家里宽带 = WiFi 没关干净；代理段 = FlClash 漏了 DIRECT。

第 2 步：MacroDroid 里点（不用写代码）

中文界面如下，英文名写在括号里。

  1. 打开 MacroDroid → 右下角 +，宏名字 po0 切网加白。
  2. 触发器（Triggers） → + → 连接（Connectivity） → 网络类型变化（Network Type Change）。
    • 勾选 WiFi 和 移动数据 / Cellular。
    • 不要勾「无连接 / None」，否则飞行模式也会空跑。
  3. 动作（Actions） → + → 插件（Plugins） → Termux（没这项 = Termux:Tasker 没装或不同源）。
    • Executable 选 po0fw.sh
    • 参数、工作目录留空
    • 不要勾「在终端里打开 / Open in terminal」
    • Wait for result 不勾也行
  4. 保存宏，打开开关。第一次会问「允许 MacroDroid 在 Termux 里跑命令」——允许。
  5. 同一个宏再加一个触发器（定时兜底）：日期/时间 → 间隔定时器（Regular Interval） → 15 分钟。

系统权限：Termux 和 MacroDroid 电池都设「无限制」；Android 13+ 给 Termux:API 开通知。切一次 WiFi ↔ 流量，通知栏应出现 po0 防火墙加白。同一出口再跑不会刷。

不要让 MacroDroid 自己 POST。 它过不了裸 IP 证书，只能勾「忽略 SSL」，token 在 URL 里等于明文。切网用 MacroDroid，上报和通知留在 Termux。

更细的排错、Windows toast 限制、launchd 重载见仓库 clash/README.md。

设计说明

  • 无脑 POST：每次直接 POST 上报当前出口 IP，服务端对已在白名单的 IP 做幂等处理（不重复占坑、不推进淘汰队列），无需客户端先 GET 查询。白名单上限 5 个，写满按写入时间先进先出淘汰。
  • C 段加白：服务端按 /24 网段加白并回显（如 203.0.113.0/24），同段内换 IP 不消耗新坑位、不推进淘汰，家宽拨号重连通常不产生新写入。
  • 自愈：每台设备都在自动检查，就算某台设备的 IP 被淘汰挤出白名单，它自己的 cron/切网事件最迟 10 分钟内会自动补回。
  • 安静运行：状态用持久化存储记账，只在出口 IP / 加白状态变化、失败或没配 token 时才推送通知（Shadowrocket、macOS、Windows、Android 同一套）。
  • 隐私：面板不显示 token；token 只保存在你自己的客户端配置里，仓库与页面不包含、不上传任何 token。
⚠️ 注意：坑位满（5/5）后继续加白会按写入时间先进先出自动淘汰最旧的 IP，无需手动清理；但频繁写入会把还在用的 IP（比如家宽）挤出白名单 —— 被挤掉的设备会在几分钟内自愈补回。

FAQ

Q: 走代理时会把代理服务器 IP 加白吗？
模块客户端（Surge 等）自带加白 API（124.221.69.228）直连规则。Clash 系 TUN 开着时必须自己加那条 IP-CIDR … DIRECT，否则服务端看到的是代理 IP。

Q: 家宽换 IP 后多久生效？
网络切换事件是即时的；纯粹的公网 IP 变更最迟 10 分钟内被 cron / launchd / 任务计划捕捉。Android + MacroDroid 切网即时，定时兜底 15 分钟。

Q: 不同客户端功能有差异吗？
核心加白逻辑完全一致。差异：不支持 $network 的客户端没有 📶 蜂窝标记；Loon 无面板（可在脚本列表手动执行）；QX 无面板与脚本参数（token 走存储 key）；Clash 系用系统调度器，不是模块。

Q: 支持几台 po0 机器？
不限，tokens 逗号分割即可，面板按 #1 #2 … 分行显示。

Q: 安卓为什么不用 MacroDroid 直接发 HTTP？
裸 IP 的 HTTPS 证书过不去，只能忽略 SSL，token 在 URL 里等于交给中间人。MacroDroid 只触发 Termux 里的脚本。
